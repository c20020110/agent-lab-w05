# 社團檔案整理報告

## 分類方式

- `communications/`：公告與宣傳文案。
- `planning/`：會議紀錄、後續事項、活動提案與雨天備案。
- `resources/`：預算與器材資料。
- `feedback/`：回饋問題。

所有分類檔都是從 `input/` 複製而來；未修改或刪除原始檔。共整理 12 個來源檔，每個來源各保留一份副本。

## 疑似重複與版本

- `announcement.txt` 與 `announcement_copy.txt` 內容完全相同。兩份都保留，無法僅憑內容判定是否應合併。
- `equipment_list.txt` 與 `equipment_backup.txt` 內容完全相同。兩份都保留，無法僅憑內容判定哪份是主要檔案。
- `proposal_final.txt`（戶外活動 v1，30 分鐘）與 `proposal_final2.txt`（室內活動 v2，20 分鐘）內容不同。兩份都保留；資料明確表示尚未定案／仍待討論，不能據檔名推定定稿。

## 待確認問題

1. 公告與器材清單的相同內容是否代表可合併，或是需要保留不同用途的副本？
2. 戶外與室內提案應如何選擇？資料指出仍待討論，未提供核定結果。
3. 紙張預算是模擬值且尚未核定；公告中的時間與地點也尚未決定。

## 檢查與限制

- 已將 input 的 12 個檔案各複製一次，並以 manifest 列出來源、目的地與分類理由。
- 已逐一比較來源與副本的檔案雜湊，確認副本內容與來源一致。
- 未修改 input 原檔；本次未做人工決策來消除重複或選定提案。
- 所有內容標示為教學模擬資料，不代表實際社團活動或核定資訊。
